# Sajan Sajan — Gotham OLED Lyrics Edit

A software-only Next.js visualizer inspired by a tiny OLED display and a dark, Gotham-like city backdrop. No physical hardware is needed.

## Run locally
1. Install Node.js (18 or newer).
2. Extract this ZIP and open the folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Visit http://localhost:3000

## Customize lyrics
Edit the `lines` array in `src/app/page.tsx`. The project includes original demo lines, not the full copyrighted lyrics of the song. Replace them with lyrics you provide or have permission to use.

## Features
- Dark Gotham-inspired skyline and bat-like emblem built with CSS (no copyrighted background image needed)
- Simulated OLED display with animated text and waveform
- Play/pause, next/previous, restart, speed control
- Responsive mobile layout
